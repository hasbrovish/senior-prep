```java
// Enums
enum VehicleType { MOTORCYCLE, CAR, TRUCK }
enum SpotType { SMALL, MEDIUM, LARGE }

// Vehicle (Strategy for parking rules)
abstract class Vehicle {
    String licensePlate;
    VehicleType type;
    abstract SpotType getRequiredSpotType();
}

// Parking Spot
class ParkingSpot {
    String spotId;
    SpotType type;
    boolean isAvailable;
    Vehicle currentVehicle;
    
    boolean canFitVehicle(Vehicle v) {
        return isAvailable && 
               type.ordinal() >= v.getRequiredSpotType().ordinal();
    }
}

// Payment Strategy
interface PaymentStrategy {
    boolean pay(double amount);
}
class CashPayment implements PaymentStrategy { }
class CardPayment implements PaymentStrategy { }

// Main Class (Singleton)
class ParkingLot {
    private static ParkingLot instance;
    List<ParkingFloor> floors;
    Map<String, ParkingTicket> activeTickets;
    RateCalculator rateCalculator;
    
    public ParkingTicket issueTicket(Vehicle v) {
        ParkingSpot spot = findAvailableSpot(v);
        if (spot == null) throw new ParkingFullException();
        spot.parkVehicle(v);
        return new ParkingTicket(v, spot);
    }
    
    public double processExit(String ticketId, PaymentStrategy pay) {
        ParkingTicket ticket = activeTickets.get(ticketId);
        double amount = rateCalculator.calculateRate(ticket);
        if (pay.pay(amount)) {
            ticket.spot.removeVehicle();
            return amount;
        }
        throw new PaymentFailedException();
    }
}
```

## LLD Template: LRU Cache

```java
class DLLNode {
    int key, value;
    DLLNode prev, next;
}

class LRUCache {
    int capacity;
    Map<Integer, DLLNode> cache;
    DLLNode head, tail; // Dummy nodes
    
    public int get(int key) {
        if (!cache.containsKey(key)) return -1;
        DLLNode node = cache.get(key);
        moveToHead(node);
        return node.value;
    }
    
    public void put(int key, int value) {
        if (cache.containsKey(key)) {
            DLLNode node = cache.get(key);
            node.value = value;
            moveToHead(node);
        } else {
            DLLNode newNode = new DLLNode(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
            if (cache.size() > capacity) {
                DLLNode lru = removeTail();
                cache.remove(lru.key);
            }
        }
    }
    
    private void moveToHead(DLLNode node) {
        removeNode(node);
        addToHead(node);
    }
}
```

# CS FUNDAMENTALS QUICK REFERENCE

## Operating System

**Process vs Thread**
| Aspect | Process | Thread |
|--------|---------|--------|
| Memory | Separate | Shared |
| Creation | Heavy | Light |
| Communication | IPC | Shared memory |

**Deadlock Conditions (All 4 required)**
1. Mutual Exclusion
2. Hold and Wait
3. No Preemption
4. Circular Wait

## Networking

**TCP vs UDP**
| TCP | UDP |
|-----|-----|
| Connection-oriented | Connectionless |
| Reliable | Unreliable |
| Ordered | Unordered |
| HTTP, FTP | DNS, Streaming |

## DBMS

**ACID**
- Atomicity: All or nothing
- Consistency: Valid states only
- Isolation: No interference
- Durability: Permanent commits

**CAP Theorem**
- Consistency + Availability + Partition Tolerance
- Can only have 2 of 3 in distributed systems

**Isolation Levels**
| Level | Dirty Read | Non-repeatable | Phantom |
|-------|------------|----------------|---------|
| Read Uncommitted | ✓ | ✓ | ✓ |
| Read Committed | ✗ | ✓ | ✓ |
| Repeatable Read | ✗ | ✗ | ✓ |
| Serializable | ✗ | ✗ | ✗ |
