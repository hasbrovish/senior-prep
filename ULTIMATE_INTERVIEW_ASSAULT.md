## 2. THE 16-HOUR DAILY BLOCK

### Standard Weekday (Mon-Fri)

```
05:30 - 06:00  WAKE + ANKI (30 min)
               └─ Review 20-30 flashcards: DSA patterns, SD concepts, Java theory
               └─ Tool: Anki desktop or mobile

06:00 - 08:30  DSA BLOCK 1: NEW PROBLEMS (2.5 hrs)
               └─ 2 new LeetCode problems in JAVA (45 min each)
               └─ 30 min: create Anki cards for each (pattern + approach + complexity)
               └─ Protocol: Read problem → think 10 min → code → test → optimize
               └─ If stuck > 20 min: read editorial, then re-solve from scratch

08:30 - 09:00  BREAK + BREAKFAST (30 min)

09:00 - 10:00  JAVA/SPRING THEORY (1 hr)
               └─ prep jqa <topic> — study P0 questions for today's topic
               └─ OR watch Programming Pathshala video (1.5x speed)
               └─ Create Anki cards for key concepts

10:00 - 12:00  DESIGN BLOCK (2 hrs) — alternating days
               ├─ Mon/Wed/Fri: SYSTEM DESIGN (HLD)
               │  └─ Read HI/Alex Xu chapter → sketch from memory → compare → fix gaps
               │  └─ Capacity estimation practice (numbers to know)
               └─ Tue/Thu/Sat: LOW LEVEL DESIGN (LLD)
                  └─ Design class diagram → implement in Java → 90 min timed
                  └─ SOLID check: identify 3 potential violations, fix them

12:00 - 13:00  BREAK + LUNCH (1 hr) — NO SCREENS

13:00 - 14:30  PROGRAMMING PATHSHALA / HELLO INTERVIEW VIDEO (1.5 hrs)
               └─ Watch assigned module for this week
               └─ Active note-taking: write 3 key insights per video
               └─ Do the assignment/homework if available

14:30 - 16:00  DSA BLOCK 2: HARD PUSH (1.5 hrs)
               └─ 1 medium (30 min) + 1 hard problem attempt (60 min)
               └─ Focus on WEAK patterns (from heatmap: prep heatmap)
               └─ Use timer — simulate real interview pressure

16:00 - 17:00  OA MOCK / TIMED CONTEST (1 hr)
               └─ Mon: Amazon-style OA (2 problems + LP essay, 90 min)
               └─ Tue: Stripe-style OA (1 problem, 3 parts, 60 min)
               └─ Wed: Flipkart-style OA (3 problems, 90 min)
               └─ Thu: Google-style (2 problems, clean code, 60 min)
               └─ Fri: Company-specific (rotate based on upcoming interviews)
               └─ Sat: Full contest simulation (LeetCode weekly/biweekly)

17:00 - 17:30  BREAK + WALK (30 min) — MANDATORY physical movement

17:30 - 18:30  BEHAVIORAL PREP (1 hr)
               └─ Mon: Write 2 new STAR stories
               └─ Tue: Practice 3 Amazon LP stories aloud (record + review)
               └─ Wed: Company culture research (read engineering blogs)
               └─ Thu: Practice "Tell me about yourself" (2 min, 3 versions: FAANG, startup, fintech)
               └─ Fri: Mock behavioral interview (self-record or with friend)
               └─ Sat: Review all recordings, identify filler words, improve

18:30 - 19:00  BREAK + DINNER (30 min)

19:00 - 20:30  DEEP DIVE / MOCK INTERVIEW (1.5 hrs)
               └─ Mon: Java concurrency deep-dive (implement a lock, thread pool)
               └─ Tue: System design mock (40 min design + 20 min review)
               └─ Wed: Machine coding mock (90 min: full LLD implementation)
               └─ Thu: DSA mock interview (2 problems, 60 min, simulate interviewer)
               └─ Fri: Full mock loop (DSA 45min + SD 45min — like real interview)
               └─ Sat: Review all week's mocks, score trends

19:30 - 21:00  COMPANY INTEL + APPLICATIONS (1 hr)
               └─ prep company <name> — read intel
               └─ prep scraper — fetch latest experiences
               └─ Apply to 2 companies per week
               └─ Read 2-3 interview experiences on LeetCode Discuss / Blind

21:00 - 21:30  SPACED REPETITION REVIEW (30 min)
               └─ Re-solve 2-3 problems from SR queue
               └─ Anki final review (10-15 cards)
               └─ prep jqa done <topic> if completed

21:30 - 22:00  PLAN TOMORROW + LOG (30 min)
               └─ prep log — record today's work
               └─ Check tomorrow's plan: prep plan <week>
               └─ Set alarm for 05:30
```

### OA Timing Protocol
```
Minute 0-3:    Read ALL problems. Categorize: Easiest → Hardest.
Minute 3-25:   Solve EASIEST problem completely. 100% on one > 50% on two.
Minute 25-55:  Tackle medium problem. BRUTE FORCE first → optimize.
Minute 55-90:  Optimize medium + attempt hard. Pseudocode for partial credit.
NEVER:         Spend 45+ min on one hard problem with easier ones unsolved.
```
