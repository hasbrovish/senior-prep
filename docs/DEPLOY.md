# PrepForge — Deployment Guide

## Architecture Overview

```

├── ui/                     ← React 19 + Vite dashboard (source code)
│   ├── src/pages/          ← 16 page components (Dashboard, Drills, Coach, etc.)
│   ├── src/components/     ← Reusable widgets (charts, timers, cards)
│   ├── src/hooks/          ← TanStack Query hooks, timer hook
│   ├── src/api.js          ← API client (fetch wrapper for 60+ endpoints)
│   ├── vite.config.js      ← Proxy :5173 → :5555, build output → ../portal/
│   └── package.json        ← React 19, Vite 6, Recharts, Lucide, React Router 7
│
├── portal/                 ← Built React app (DO NOT edit — auto-generated by `npm run build`)
│   ├── index.html          ← Vite build output
│   └── assets/             ← Hashed JS + CSS bundles
│
├── app/                    ← FastAPI server (production-grade)
│   ├── main.py             ← App entry point, middleware, SPA catch-all, static assets
│   ├── scheduler.py        ← Background jobs (daily scrape, LC sync, morning brief)
│   └── routers/            ← API endpoints (60+ routes)
│       ├── progress.py     ← /api/progress, /api/gaps, granular LC/apply/bug/retro/SR
│       ├── intel_routes.py ← /api/intel/* (trending, experiences, scrape)
│       ├── coach.py        ← /api/coach (stream + non-stream), KB management
│       ├── practice.py     ← /api/drill, /api/mock, /api/lld, /api/behavioral, /api/brief
│       ├── career.py       ← /api/career/* (ladder, skill-map, weekly-plan)
│       └── feedback.py     ← /api/log, /api/plan/daily, /api/plan/weekly
│
├── intel/                  ← Intelligence engine (domain logic)
│   ├── db.py               ← SQLite database (9+ tables, WAL mode)
│   ├── coach.py            ← Claude API integration
│   ├── analyzer.py         ← Gap analysis, trending topics
│   ├── scraper.py          ← Experience aggregator
│   ├── drill.py            ← 211 DSA problems, company banks
│   ├── mock_engine.py      ← Mock score tracking
│   ├── lld_engine.py       ← 20 LLD problems
│   ├── behavioral.py       ← Amazon LP gap detector
│   ├── feedback_engine.py  ← Activity logging, LLM adaptive plans
│   └── sources/            ← LeetCode, Reddit, HN scrapers
│
├── prep.py                 ← CLI (55+ commands, still works alongside UI)
├── Dockerfile              ← Multi-stage: Node (build UI) → Python (serve)
├── docker-compose.yml
└── requirements.txt
```

## Option A — Local Development (Day-to-Day)

### Quick start (production build)
```bash
# 1. Install Python dependencies
pip3 install -r requirements.txt

# 2. Install and build the React UI
cd ui && npm install && npm run build && cd ..

# 3. Start the server
prep portal
# OR: uvicorn app.main:app --reload --port 5555

# 4. Open browser
open http://localhost:5555
# API docs: http://localhost:5555/docs (dev mode only)
```

### Development mode (hot reload)
```bash
# Terminal 1: API server with auto-reload
uvicorn app.main:app --reload --port 5555

# Terminal 2: Vite dev server with hot module replacement
cd ui && npm run dev
# Opens at http://localhost:5173 — proxies /api/* to :5555

# Edit React code → instant reload in browser
# Edit Python code → uvicorn auto-restarts
```

### Rebuild UI after changes
```bash
cd ui && npm run build
# Outputs to portal/ — FastAPI serves it at /
```

### First-time setup
```bash
# Set API key (get from console.anthropic.com)
export ANTHROPIC_API_KEY=sk-ant-YOUR-KEY

# Populate intel DB (run once)
prep scrape
```

## Option B — Docker (Multi-Stage Build)

The Dockerfile has two stages:
1. **Node 22** — installs npm deps, runs `vite build`, outputs to `portal/`
2. **Python 3.11** — installs pip deps, copies app + built UI, runs uvicorn

```bash
# Build and run
docker-compose up

# Or build manually
docker build -t prepforge .
docker run -p 5555:8080 \
  -e ANTHROPIC_API_KEY=sk-ant-YOUR-KEY \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/logs:/app/logs \
  prepforge
```

The `docker-compose.yml` maps port 5555 → 8080 (container), mounts `data/` and `logs/` for persistence.

## Option C — Railway.app (Cloud, Recommended)

Railway gives $5/month free credit — enough for this app (~$2-3/month with the multi-stage build).

### Steps:

**1. Push to GitHub**
```bash
git add .
git commit -m "PrepForge with React dashboard"
git push origin main
```

**2. Deploy to Railway**
```bash
# Install Railway CLI
npm install -g @railway/cli   # OR: brew install railway

# Login and deploy
railway login
railway init
railway up
```

Railway auto-detects the Dockerfile, runs the multi-stage build (Node → Python), and deploys.

**3. Set environment variables** (Railway Dashboard → Variables)
```
ANTHROPIC_API_KEY = sk-ant-YOUR-KEY        # Required: AI Coach
ENV = production                            # Hides /docs endpoint
PORTAL_SECRET =                             # Optional: password-protect portal
REDDIT_CLIENT_ID =                          # Optional: Reddit scraping
REDDIT_CLIENT_SECRET =                      # Optional: Reddit scraping
NTFY_TOPIC =                                # Optional: phone push via ntfy.sh
NTFY_TOKEN =                                # Optional: private ntfy.sh topics
```

**4. Persist your data** (IMPORTANT)
- Railway Dashboard → Add Volume → Mount at `/app/data`
- This keeps `interviews.db` and `portal_data.json` across deploys
- Also add a volume at `/app/logs` for `progress.json`

**5. Get your URL**
Railway gives you: `https://your-project.railway.app`

### Build time
- First deploy: ~3-4 minutes (npm ci + vite build + pip install)
- Subsequent deploys: ~2-3 minutes (Docker layer caching)

```bash

export ANTHROPIC_API_KEY=sk-ant-YOUR-KEY

# Run with systemd

```

```ini
[Unit]
Description=PrepForge Intelligence Engine
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/senior-prep
Environment=ANTHROPIC_API_KEY=sk-ant-YOUR-KEY
Environment=ENV=production
ExecStart=/usr/bin/python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8080
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable prepforge
sudo systemctl start prepforge
```

## UI Development Workflow

### Adding a new page

1. Create `ui/src/pages/NewPage.jsx`
2. Add route in `ui/src/App.jsx` (both the `NAV` array and `<Routes>`)
3. Create API functions in `ui/src/api.js` if needed
4. Add TanStack Query hooks in `ui/src/hooks/useProgress.js`
5. Build: `cd ui && npm run build`

### Key dependencies

| Package | Version | Purpose |
|---------|---------|---------|
| react | 19.x | UI framework |
| react-router-dom | 7.x | Client-side routing (16 routes) |
| @tanstack/react-query | 5.x | API data caching + mutations |
| recharts | 2.x | Charts (Radar, Radial, Line, Bar, Pie) |
| lucide-react | latest | Icons |
| vite | 6.x | Build tool + dev server |

### Vite proxy configuration

In development, Vite proxies all `/api/*` requests to FastAPI:

```javascript
// ui/vite.config.js
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:5555',
      changeOrigin: true,
    },
  },
},
```

In production, `npm run build` outputs to `portal/` which FastAPI serves directly at `/`. The SPA catch-all in `app/main.py` ensures React Router works for all non-API paths.

## Security Checklist

- [x] API keys in env vars (never in code)
- [x] `.env` in `.gitignore`
- [x] `portal/assets/` in `.gitignore` (build artifacts)
- [x] `ui/node_modules/` in `.gitignore`
- [x] Rate limiting: 30 req/min on AI endpoints, 120/min on others
- [x] CORS locked to specific origins (`:5555`, `:5173`, `:3000`)
- [x] Non-root Docker user
- [x] No raw scraped text exposed via API (`body_raw` stripped)
- [x] No PII fields in AI prompts (scrubbed before sending)
- [ ] Optional: Add PORTAL_SECRET env var to password-protect portal
